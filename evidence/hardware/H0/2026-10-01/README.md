## 4. CAN Pal 背面核对

- `CAN Bus Transceiver`；
- `TJA1051T/3`；
- `3-5V Vin/logic w/5V boost`；

背面模块规格和外观子项判定为 **PASS（照片可见范围）**。但这些字符属于 PCB 产品丝印，不是正面 SOIC-8 收发器实体的激光顶标；它不能排除实际装片与 PCB 声明不一致。
