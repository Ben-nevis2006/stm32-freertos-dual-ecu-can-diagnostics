## 3. 可复核事实

- 两张照片均显示目标模块正面及绿色端子下方、终端开关左侧的中央 SOIC-8 芯片；
- `CANPAL-02` 照片中端子上的 `02` 手写标记可辨；`CANPAL-01` 的板号对应关系沿用既有受控实物编号与照片序列；
- 两块目标芯片表面均可见极弱字符痕迹，但原图像素、对焦和反差不足，无法可靠逐字抄录；
- PCB 背面 `TJA1051T/3` 丝印只描述模块声明，不能代替实体芯片顶标；
- 照片未显示模块接线或通电动作，但静态照片本身不构成功能或电气验证。

## 4. 判定

本批照片判定为 **INSUFFICIENT FOR TOP-MARK IDENTIFICATION**。这表示证据质量不足，不表示芯片或模块本身 FAIL。

- D-02 的 CAN Pal 背面模块规格子项保持 **CLOSED**；
- D-02 的 `CANPAL-01/02` 实体芯片顶标子项保持 **OPEN**；
- 在两块芯片顶标均清晰可辨前，不连接 CAN Pal、NUCLEO 或任何板间线，不进入 H2 主动电气步骤。

## 5. 下一次补拍要求

1. 全部设备断电、无线，模块平放在桌面，擦净手机镜头；
2. 用台灯或另一部手机从芯片侧上方斜照，缓慢旋转模块或光源，直到激光字符呈银白色；避免正面直射形成整片反光；
3. 手机与 PCB 平行，使用微距模式或 2×/3× 光学倍率，点击中央 SOIC-8 芯片表面锁定对焦；不要贴得近到低于手机最短对焦距离；
4. 若一张图无法同时兼顾板号和字符，每块板拍两张：先拍含 `01/02` 的整体定位图，再保持模块不动拍中央芯片微距图；
5. 拍后先在手机相册放大，确认每一行字符都能逐字读取，再提交原图。
