## 3. H1-00 判定

| 检查项 | 判定 | 依据与边界 |
|---|---|---|
| 实体身份 | PASS | 板上丝印 `NUCLEO-F103RB / NUF103RBSAU1`，手写 ID `01` 可见 |
| 板卡外观与接口 | PASS（照片可见范围） | 未见明显破损、异物或接口机械损伤；静态正面照不替代通电功能验证 |
| 外部连接隔离 | PASS（照片可见范围） | CN1、Arduino/Morpho 排针均未连接；照片拍摄时未上电 |
| USB 插头机械规格 | PASS | 补拍照片确认设备端为 USB Mini-B，不是 DC 圆头 |
| USB 数据能力 | 待 H1-01 验证 | 插头外形不能证明线缆内部存在并连通 D+/D-；以 Windows 的 ST-LINK/VCP 枚举为准 |

结论：`NUCLEO-01` 的 H1-00 照片预检通过，可以在“不接任何外设或 12 V、一次只接一块板”的边界内进入 H1-01。此结论不代表 ST-LINK、VCP、目标 MCU 或线缆数据功能已经通过。

## 4. 识别更正留痕

第一张照片中 Mini-B 插头近似正对侧面，曾被误判为 DC 圆头。第二张补拍照片展示了完整金属壳体和 Mini-B 轮廓，已据此更正。工程结论以后者和实际枚举结果为准；不删除第一张照片，以保留判断更正链路。

## 5. 下一证据

H1-01 需要继续归档：

1. USB 接入后的 Windows 设备管理器截图，包含 ST-LINK 设备名及虚拟串口 COM 号；
2. 至少 30 s 无反复掉线的现场记录；
3. STM32CubeProgrammer 的探针序列号、固件版本、目标电压、目标 MCU / Device ID 和 Flash 容量只读截图；
4. 明确记录无异味、异常发热、火花或插头松动。

在上述证据形成前，不得把 H1-01 或 `NUCLEO-01` 写成 PASS。
