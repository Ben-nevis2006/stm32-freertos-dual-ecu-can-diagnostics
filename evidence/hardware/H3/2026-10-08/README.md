## 引出线身份

执行人按电阻分段复核后确认当前映射：

| 网络 | 当前线色 | 后续电气目标 |
|---|---|---|
| `T` | 棕色 | Node B `3V3` |
| `S` | 黑色（2026-10-07 近照最右侧） | Node B `A0 / PA0 / ADC1_IN0` |
| `G` | 红色 | Node B `GND` |

当前线色与常见电源约定相反：红色被用作 GND，黑色被用作模拟信号。为降低 H3-02 误接概率，在连接 Node B 前必须保持全断电，并采用下列二选一控制：

1. 推荐把外部跳线规范为 `红=T/3V3、棕=S/A0、黑=G/GND`，再复测三个阻值；或
2. 若不换线，则在两端增加不可脱落且不可混淆的 `T/S/G` 标签，并由第二次逐线核对确认。
