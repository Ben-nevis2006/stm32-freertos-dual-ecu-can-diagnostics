# H3 FAN-02B 低压动态波形证据（2026-10-13）

## 1. 目的与边界

本目录记录 Node A `PC7/D9/TIM3_CH2` 在风扇完全隔离、外部 `10 kΩ` 上拉至同板 `3V3` 条件下的 B1 触发动态波形。它用于在真实风扇接入前验证 `100→50→25→0→100→最终50%` 的顺序和电平形态。

## 3. 结果摘要

- `D9—3V3=9.985 kΩ`；`3V3—GND`、`D9—GND` 均不蜂鸣；
- 默认 `25 kHz / 50%` 稳定；
- Run01 在 COM7 监听进程异常结束时提前回到 50%，归档为 `INVALID / 测试工具干扰`；
- Run02 保持同一硬件但完全取消 COM/ST-Link 访问，五档按预定顺序完整出现并最终恢复 50%；
- 人工观察只支持每档“约 10 s”，不冒充毫秒级定时精度。
- 接入真实风扇后，默认 50%、100%、50%、25%、0%、再次 100% 和最终 50% 均按顺序稳定；0% 稳定停转，随后可重新起转；
- 真实负载下 PWM 约 `25 kHz`、高/低电平 `5.04 V / -160 mV`，USB 未断连，无其他异常；
- 按规定逆序断电，最终残压 `0.04 V`。

## 4. 判定

`FAN-02B` 的低压动态波形与单只真实风扇五档短时响应均判定为 **PASS**，Fan PWM 子项由此关闭。Tach/PPR、绝对转速、长期运行和系统温控闭环仍不由本证据证明。

## 5. 真实风扇电气边界说明

`5.04 V` 低于既定风扇 PWM 上拉绝对上限 `5.25 V`。`-160 mV` 作为示波器 1X 探测条件下的边沿小幅负向欠冲原值保留，不美化为 `0 V`；该量级没有伴随低平台异常、USB 断连或控制失效。PC7 开漏直连仍只适用于能够保证 Node A 先上电、后断电的受控接法，否则最终硬件应增加外部晶体管隔离。
