# H3 INA260 实物身份、I2C 隔离与模块无应答证据（2026-10-20）

## 1. 时间与范围

本目录先记录 2026-10-20 实际完成的 `INA-00A / INA-00B`，随后按真实推进顺序追加
`INA-02D～INA-02F` 的 I2C 波形隔离与地址网络复核。前一阶段 Node A、Node B、12 V
适配器与风扇均断电，残压报告为 `0.1 V`，`INA260-01` 完全孤立；后一阶段只增加
Node A USB 与 `Vcc/GND/SCL/SDA` 四条 3.3 V 低压连接，Node B、风扇 12 V、ALERT、
VBus、Vin+、Vin-、绿色端子和负载继续隔离。

本轮关闭了实物身份、接口可追溯性、接线前无源筛查、主控 I2C 事务到达模块排针以及
默认地址网络复核；同时形成 `INA260-01` 在所有扫描地址均不应答的模块级硬件 HOLD。
它没有证明寄存器身份、测量精度、12 V 高边方向、带载电流、功率读数、ALERT 或长期
温升通过。

## 3. INA-00A 隔离状态

- 两端全断电，残压 `0.1 V`；
- INA260 未接任何线；
- 正反面照片已归档；
- 可见范围内未发现端子破裂、排针明显弯折、松脱焊点或相邻焊盘锡桥。

`INA-00A` 判定为 **PASS（实物身份、接口与可见外观范围）**。照片不能逐字确认芯片顶部
激光标识，也不能代替寄存器 Manufacturer ID / Die ID 身份验证。

## 4. INA-00B 无源测量

| 测量项 | 现场结果 | 判读 |
|---|---:|---|
| 表笔短接基线 `Rlead` | `0.22 Ω` | 本轮低阻路径的分辨边界；不作为四线毫欧测量 |
| `Vcc-GND` 蜂鸣 | 否 | 未见直接低阻短路 |
| `Vcc-GND` 电阻，红表笔接 Vcc | 约每秒上升 `3 MΩ`，最终超出 `200 MΩ` 量程 | 与板载电容/半导体网络被欧姆档充电相符 |
| `Vcc-GND` 电阻，黑表笔接 Vcc | 从十几 `MΩ` 上升，增速约每秒 `1 MΩ` 至 `4 MΩ` 以上，最终超出 `200 MΩ` 量程 | 方向相关且持续升高，不是稳定低阻短路 |
| `Vcc-SCL` | `10.056 kΩ` | 与板载约 10 kΩ I2C 上拉一致 |
| `Vcc-SDA` | `10.028 kΩ` | 与板载约 10 kΩ I2C 上拉一致 |
| `GND-SCL` / `GND-SDA` / `SCL-SDA` | 均不蜂鸣 | 未见信号线对地或互相低阻短接 |
| `SDA-Alert` / `Alert-VBus` | 均不蜂鸣 | 未见相邻功能网络低阻短接 |
| `VBus-Vin+` | 蜂鸣；`0.043 Ω` | 与板载 VB 桥把 VBus 采样接到 Vin+ 的预期一致 |
| `Vin+-Vin-` | 蜂鸣；`0.044 Ω` | 与 INA260 内置毫欧级分流路径的预期一致 |

`0.043 Ω / 0.044 Ω` 均低于本轮两线表笔短接基线 `0.22 Ω`，因此不能把显示值减去表笔
基线，也不能据此声称测得了 INA260 内置分流器的精确阻值。本轮只将其作为“应导通路径
确实连续、未开路”的证据；精密毫欧值需要四线/Kelvin 方法，且不是 H3 接线前门禁。

`INA-00B` 判定为 **PASS（孤立、断电无源准入范围）**。结合照片，当前未发现会阻止
3.3 V 只读 I2C 接入的开路或低阻短路证据。下一步仍必须先刷写并核验只读镜像，再在
全断电状态只接 `Vcc/GND/SCL/SDA`；`Alert/VBus/Vin+/Vin-/绿色端子/12 V/风扇` 继续
保持断开。

## 5. 结论边界

- 通过：实物正反面身份、接口丝印、可见外观、I2C 上拉数量级、关键隔离网络和设计内
  低阻通路的连续性；
- 后续实测：主控确实发出约 `100 kHz` 地址事务且事务到达模块排针，但模块在 `0x40`
  及完整扫描范围均不 ACK；详见第 6～8 节；
- 尚未通过：Manufacturer ID、Die ID、空载读数、高边 12 V 电压/电流/功率读数和方向性；
- 禁止外推：本轮 PASS 不构成任意 12 V 接线或带载授权，也不证明 15 A 额定能力、精度、
  动态响应、ALERT、热性能或最终线束可靠性。

## 6. INA-02D 方法修正：先排除主控侧忙状态与误触发

Node A 上电后，模块排针静态实测 `Vcc=3.230 V、SCL=3.223 V、SDA=3.224 V`，期间
没有 USB 断连。诊断日志在目标探测前记录 I2C1 为非 BUSY、无 HAL 错误、PB8/PB9 均为
高电平；对 `0x40` 的定向探测以及随后完整 7-bit 扫描均无 ACK。早期单次触发使用复位/
既有通信活动启动，示波器先捕获到同步窄负脉冲，不能证明该脉冲就是目标地址帧，因此
两张照片只作为“触发方法失败并被纠正”的过程证据，不用于故障定性。

## 7. INA-02E/02F B1 静默事务与测点推进

为避免 UART 和复位活动抢先触发，诊断镜像改为：B1 按下后先静默执行一次 `0x40` 地址
探测，完成后才输出日志。`20:05` 在中间面包板节点捕获到约 `100 kHz` 的完整地址周期，
应答位没有被从机拉低。由于该测点只能证明事务到达中转节点，不能排除中转到模块之间的
接触问题，探钩随后直接移至 INA260 模块 SCL/SDA 焊接排针。

`20:13` 的模块端捕获重现相同约 `100 kHz` 地址周期及无 ACK，排除了本次台架中 Node A
到面包板、面包板到模块排针的信号路径问题。示波器对 SDA 非周期帧给出的自动频率值不
作为 I2C 时钟结论；时钟以 CH1/SCL 的约 `100 kHz` 和逐位波形判读。

## 8. 地址网络复核与模块级硬件 HOLD

全断电后，现场分别测量 A0/A1 未桥接焊盘两侧到模块 GND：

| 测量点 | 实测值 | 判读 |
|---|---:|---|
| A0 小面积左侧焊盘-GND | `4.607 kΩ` | 与 A1 小焊盘数值一致，属于共用 Vcc 侧的在路等效阻值 |
| A0 大面积右侧焊盘-GND | `9.988 kΩ` | A0 信号侧约 10 kΩ 下拉正常 |
| A1 小面积左侧焊盘-GND | `4.609 kΩ` | 与 A0 小焊盘数值一致，属于共用 Vcc 侧的在路等效阻值 |
| A1 大面积右侧焊盘-GND | `10.044 kΩ` | A1 信号侧约 10 kΩ 下拉正常 |

两条地址信号均保持默认下拉且焊盘未桥接，因此默认 `0x40` 网络成立；完整扫描零 ACK
同时排除了“仅仅接成其他合法地址”的解释。结合既有约 10 kΩ SCL/SDA 上拉、静态电压、
主控状态、面包板端和模块端波形，`INA260-01` 判定为 **FAIL / HARDWARE HOLD（模块级
无应答）**。

该结论精确到模块边界，但在不接触 TSSOP 细脚、不进行破坏性返修的条件下，不能继续区分
芯片电源脚/数字脚贴装、板内走线、芯片损伤或器件真实性。停止对 Node A、I2C 参数和同一
线束重复排查；当前模块禁止接入 12 V 或负载。下一步为更换/独立修复 INA260 模块，并从
四线无源准入、静态 3.3 V、`0x40` ACK、Manufacturer ID、Die ID 依次重验。
