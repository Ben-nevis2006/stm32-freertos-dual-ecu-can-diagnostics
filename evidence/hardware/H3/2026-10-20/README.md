## 4. INA-00B 无源测量

| 测量项 | 现场结果 | 判读 |
|---|---:|---|
| 表笔短接基线 `Rlead` | `0.22 Ω` | 本轮低阻路径的分辨边界；不作为四线毫欧测量 |
| `Vcc-GND` 蜂鸣 | 否 | 未见直接低阻短路 |
| `Vcc-GND` 电阻，红表笔接 Vcc | 约每秒上升 `3 MΩ`，最终超出 `200 MΩ` 量程 | 与板载电容/半导体网络被欧姆档充电相符 |
| `Vcc-GND` 电阻，黑表笔接 Vcc | 从十几 `MΩ` 上升，增速约每秒 `1 MΩ` 至 `4 MΩ` 以上，最终超出 `200 MΩ` 量程 | 方向相关且持续升高，不是稳定低阻短路 |
| `Vcc-SCL` | `10.056 kΩ` | 与板载约 10 kΩ I2C 上拉一致 |
| `Vcc-SDA` | `10.028 kΩ` | 与板载约 10 kΩ I2C 上拉一致 |
| `GND-SCL` / `GND-SDA` / `SCL-SDA` | 均不蜂鸣 | 未见信号线对地或互相低阻短接 |
| `SDA-Alert` / `Alert-VBus` | 均不蜂鸣 | 未见相邻功能网络低阻短接 |
| `VBus-Vin+` | 蜂鸣；`0.043 Ω` | 与板载 VB 桥把 VBus 采样接到 Vin+ 的预期一致 |
| `Vin+-Vin-` | 蜂鸣；`0.044 Ω` | 与 INA260 内置毫欧级分流路径的预期一致 |

`0.043 Ω / 0.044 Ω` 均低于本轮两线表笔短接基线 `0.22 Ω`，因此不能把显示值减去表笔
基线，也不能据此声称测得了 INA260 内置分流器的精确阻值。本轮只将其作为“应导通路径
确实连续、未开路”的证据；精密毫欧值需要四线/Kelvin 方法，且不是 H3 接线前门禁。

`INA-00B` 判定为 **PASS（孤立、断电无源准入范围）**。结合照片，当前未发现会阻止
3.3 V 只读 I2C 接入的开路或低阻短路证据。下一步仍必须先刷写并核验只读镜像，再在
全断电状态只接 `Vcc/GND/SCL/SDA`；`Alert/VBus/Vin+/Vin-/绿色端子/12 V/风扇` 继续
保持断开。

- 通过：实物正反面身份、接口丝印、可见外观、I2C 上拉数量级、关键隔离网络和设计内

  动态响应、ALERT、热性能或最终线束可靠性。
