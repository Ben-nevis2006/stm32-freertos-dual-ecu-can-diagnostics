### 在路阻值排查边界

边界操作期间还观察到断电在路 `S-G` 约 `5～6 kΩ`、`T-S` 约 `6.46 kΩ` 等低于元件标称的读数。逐支路隔离后：

- `T` 与 `A0` 都断开时，`S-G=9.93 kΩ`，固定电阻正常；
- 仅断开 `A0` 时，`S-G≈6.2 kΩ`；仅断开 `T` 时，`S-G≈5.6 kΩ`；
- `T-S` 在两支路都断开时约 `11.49 kΩ`，只断 A0 时约 `6.36 kΩ`。

因此低读数来自未上电 MCU 的 ADC/电源/保护路径与元件形成并联网络，不能把在路等效阻值直接当作单只 NTC 或固定电阻的失效判据。该结论来自隔离前后对照，不依赖对板内单一电流路径的猜测。
