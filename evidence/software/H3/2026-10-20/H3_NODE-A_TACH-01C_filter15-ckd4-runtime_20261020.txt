结论：PASS（原始 Tach 捕获完整性）；PPR/RPM 仍为 TBD/INVALID

一、刷写前状态与身份门禁
------------------------

现场执行人报告：

  TACH-01C刷写前已就绪：风扇12V断电，残压=正常，仅Node A USB上电，RC/A0保持

“残压=正常”是现场原话，本轮没有记录具体伏值；因此只保留为操作员状态确认，不把它
改写成精确的 `<0.5 V` 测量值。软件侧随后复核：

- Git HEAD=3393b0b，工作区为空；
- ELF size=1102172 bytes；
- ELF SHA-256=A0440CEECD3C0999210A3ABDF20B04D1315E3BA0E9A388BFCA44F9D5203E9DFE；
- CubeProgrammer 2.23.0 只发现一个 ST-Link Probe；
- 冻结 Node A ST-Link SN=066BFF575151676667043206；
- VCP=COM7，Windows 状态 OK。

首次自动门禁脚本因 CubeProgrammer 同时在 ST-Link Probe 区块和 UART 区块打印同一 SN，
把两次文本出现误判成两个目标并在写入前主动停止。该次没有执行 download。随后只统计
`ST-Link Probe N` 条目并校验 Probe 0 的完整 SN，得到 probes=1 后才放行写入。这是主机
解析规则修正，不是硬件断连或失败刷写。

------------------------

写入目标为上述 ELF，CubeProgrammer 报告：

  File size = 35.40 KB
  File download complete
  Download verified successfully
  Software reset is performed

为避免把刷写工具复位与串口启动日志割裂，随后先打开 COM7，再按同一冻结 SN 触发一次
软件复位并持续采集 15.5 s。复位后的启动身份原文为：

  H3,A,TACH_CAPTURE_PROFILE,pin=PA0,timer=TIM2_CH1,edge=falling,
  timer_hz=100000,tick_us=10,ic_filter=15,ckd_div=4,

该行同时确认 TACH-01C 的 PA0/TIM2_CH1、下降沿、100 kHz/10 us、ICFilter=15、CKD=DIV4
和 PPR/RPM 边界，而不是沿用 TACH-01B 的运行假设。

三、风扇 12 V 断开基线
----------------------

同一次可观察复位后，从 tick=552 到 tick=15000 共取得 15 个约 1 s 窗口，跨度
14.448 s。每个窗口均为：

- state=WAIT_FIRST_EDGE；
- edge_total=0；
- sample_total=0；
- window_samples=0；
- zero_delta=0。

结论：TACH-01C 无风扇零边沿基线 PASS。10 s 后 H2 开始出现 CAN tx_fail 和
ESR=0x00800033；本轮 Node B 未上电，这是无 ACK 的既知旁路现象，不属于 Tach 边沿，
也没有改变上述五项零值。

五、统计与判定
--------------

- 连续窗口数：25；
- 首末窗口跨度：(311557-286741) ms = 24.816 s；
- 首末累计边沿增量：8358-7304 = 1054；
- 平均捕获率：1054 / 24.816 = 42.472598 edge/s；
- 每窗样本数：43～45；25 个窗口所报告的 window_samples 合计 1098；
- last_ticks 范围：2346～2372，即 23.46～23.72 ms；
- 所有窗口合并后的最短/最长周期：2333～2375 ticks，即 23.33～23.75 ms；
- 对应逐窗即时频率范围：42.158～42.625 Hz；
- edge_total-sample_total 始终为 1，符合首个边沿没有前一周期样本；
- zero_delta 全程为 0；
- 约 11.5 ms 半周期：0/25 窗口；
- 10 us 或其他微秒级极短周期：0/25 窗口；
- state 全部为 PERIOD_VALID，COM7 采集后仍为 Windows OK。

TACH-01B 的 20 个窗口中有 17 个被半周期或 10 us 最短周期污染；TACH-01C 在保持
ICFilter=15、硬件 RC、下降沿、计数 tick 与 PWM 不变的条件下，将 CKD 从 DIV1 改为
DIV4 后，25/25 个窗口均落入单一完整周期带。改善既体现在平均率，也体现在每个窗口的
last/min/max 和 zero_delta，不是用软件平均值掩盖坏周期。

最终判定：TACH-01C = PASS（默认 50% 稳态下的原始 Tach 捕获完整性）。该结论证明当前
实物与固件配置可产生可信的逐周期输入，但仍不证明：风扇每转脉冲数 PPR、绝对 RPM、
不同 PWM 转速下的量程、停转/断线故障阈值或长期运行。因此 PPR 保持 TBD、RPM 保持
INVALID；下一步必须单独关闭 PPR/RPM 门禁，不能从本次 42.47 Hz 直接猜测绝对转速。
