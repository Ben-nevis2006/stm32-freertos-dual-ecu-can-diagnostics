## 2. Gate 目标与边界

Gate H3 按“一次只增加一个外设”的原则，依次建立 NTC、Fan PWM、Tach/PPR 和 INA260 的独立输入/输出证据。每个外设必须能靠自己的连接照片、原始测量或结构化日志判断成败，不能依赖完整温控闭环才能验收。

H3 的第一个对象固定为 Node B NTC 低压采集链。当前步骤 H3-00 只完成准入审计、接线方向、换算公式、安全边界和证据规则冻结；不接线、不通电、不修改或刷写固件。

## 4. 冻结的 NTC 电气拓扑

### 4.1 接线定义

```text
Node B 3V3 ---- NTC-01 ----+---- Node B A0 / CN7-28 / PA0 / ADC1_IN0
                           |
                       R10K-01
                        9.911 kΩ
                           |
Node B GND ----------------+
```

冻结规则：

1. `NTC-01` 位于分压上臂，连接 `3V3` 与 ADC 测量点；
2. `R10K-01` 位于分压下臂，连接 ADC 测量点与同一块 Node B 的 `GND`；
3. ADC 测量点只连接 Node B 的 `A0 / CN7-28 / PA0`；
4. NTC 和固定电阻均无极性，但三个网络 `3V3 / A0 / GND` 不可互换；
5. 禁止使用 `5V`、`VIN` 或任何 `12 V` 节点；
6. 初次验证不并联滤波电容，不同时接入 INA260、Fan、Heater 或其他新外设；
7. 已通过的 H2 CAN 线束若保留，H3-NTC 期间不得改动；它只能作为既有回归基线，不能替代 NTC 自身证据。

### 4.2 冻结理由

该方向使温度升高时 `R_NTC` 下降、`V_ADC` 和 `ADC_raw` 上升，便于现场观察和日志复核。NTC 上支路开路时，测量点由 `R10K-01` 拉向 GND；NTC 被短接时，测量点趋近 3.3 V。软件仍必须先做信号有效性判断，再允许温度值进入控制或 Fault 逻辑。

注意：若断开的是 `A0` 跳线而不是 NTC 上支路，MCU 引脚会悬空，读数可能不确定；不能把“A0 线断开”机械等同于“NTC 开路约 0 V”。该场景后续必须单独验证或由 frozen/stuck plausibility 覆盖。

## 5. 冻结的换算模型

### 5.1 ADC 与电压

12-bit ADC 的记录模型为：

```text
V_ADC = ADC_raw / 4095 × V_DDA
```

`V_DDA` 使用实测值时必须记录测量方法和时间；使用 `3.3 V` 名义值时，日志和报告必须明确标记为 nominal/configured，不得描述为实测电压。

### 5.2 电压与 NTC 阻值

对本文件冻结的“NTC 上拉、固定电阻下拉”拓扑：

```text
V_ADC = V_DDA × R_FIXED / (R_NTC + R_FIXED)

R_NTC = R_FIXED × (V_DDA / V_ADC - 1)
      = R_FIXED × (4095 - ADC_raw) / ADC_raw
```

初始使用：

```text
R_FIXED = 9911 Ω     // H0 筛查实测值
```

当 `ADC_raw` 接近 0 或 4095 时，不执行普通除法换算，应先进入边界/故障分支。具体 raw 阈值不在 H3-00 凭空设定，待 H3 实测噪声、供电和开短路样本后冻结。

### 5.3 阻值与温度

初始温度模型采用 Beta 方程：

```text
T_K = 1 / (1 / 298.15 + ln(R_NTC / 10000) / 3950)
T_C = T_K - 273.15
```

其中 `R0=10 kΩ @ 25°C`、`B=3950 K` 来自采购规格，尚未由多温点实测独立证明。因此 H3 初期输出应写为 `temp_nominal_c` 或等价名称；在没有参考温度计和多温点标定前，只验收趋势、合理性和故障边界，不宣称绝对温度精度。

### 5.4 计算锚点（仅用于接线前 sanity check）

| 输入假设 | 预期比值/结果 | 证据边界 |
|---|---|---|
| `R_NTC=10.30 kΩ`、`R_FIXED=9.911 kΩ` | `V_ADC/V_DDA≈0.4904`；若 `V_DDA=3.3 V`，约 `1.618 V`、raw≈`2008` | 规划锚点，不是现场通过区间 |
| `R_NTC=10.00 kΩ`、`R_FIXED=9.911 kΩ` | `V_ADC/V_DDA≈0.4978`；若 `V_DDA=3.3 V`，约 `1.643 V`、raw≈`2038` | 规划锚点，不是现场通过区间 |
| NTC 上支路开路、A0 仍连接 | 测量点趋近 `0 V`、raw 趋近 `0` | 后续必须实测噪声后再定阈值 |
| NTC 短接 | 测量点趋近 `V_DDA`、raw 趋近 `4095` | 后续必须实测噪声后再定阈值 |

### 18.3 冻结的首选电气方案

在现场实测 PWM 开路电压满足 PC7/接口约束的前提下，首选方案保持为：

```text
PSU12V-01 +12 V  -> FAN-01 Power
PSU12V-01 GND    -> FAN-01 GND
                    -> Node A GND（只在前序检查通过后建立单点公共地）
FAN-01 PWM       -> Node A PC7 / D9 / TIM3_CH2（AF Open-Drain，内部上下拉关闭）
FAN-01 Tach      -> 本 PWM 子项暂不连接；留给后续 Tach/PPR 子项
PST 额外接口     -> 不使用、单独绝缘固定
```

风扇 12 V 功率不经过 NUCLEO 或面包板电源轨；Node A 初期继续由 USB 供电，12 V 不得进入 `3V3`、`5V`、`VIN` 或 GPIO。PWM 只承担开漏下拉信号，不给风扇供电。首轮只使用一只风扇，不接 PST 串联接口。

最终/长期功率线束仍不得使用松散杜邦线。仅在 `FAN-00D` 单只 `0.09 A` 风扇的短时隔离验证中，允许把两根经过逐针通断与端到端极性复核的公头测试线作为可拆转接：从完整延长线母座的 `Pin 1/Pin 2` 引到 DC 螺丝端子，跳过面包板并做机械固定；`Pin 3/Pin 4` 留空。该临时例外不得外推到 Heater、INA260 高边、长期运行或最终装配。

若实测 PWM 开路电压超出 PC7/接口约束，或实物接口无法确认，则本直连方案自动撤回，继续 HOLD；必须另行冻结具体晶体管、电阻、默认态和失效态后才能继续。现有 BOM 只把外部 NPN/MOSFET 写成后备方向，没有冻结具体器件与阻值，因此不能现场临时拼接替代。

### 18.4 停止条件

任一步出现以下任一情况都立即断开适配器市电侧并保持 HOLD：极性/针脚不明确，表笔或端子可能相碰，输出明显漂移，USB/ST-LINK 反复掉线，风扇不启动或剧烈抖动，异味、异响、火花、冒烟、线缆/端子/适配器异常发热，或 PWM 开路电压不满足已冻结约束。不得靠反复插拔、交换未知线、堵转风扇或“先接 MCU 看看”定位。

### 18.8 FAN-00C 延长线无源映射（2026-10-12）

公头与母座的插接面同时朝向观察者、防呆结构同向时，现场临时编号结果为：

```text
M1 -> F4
M2 -> F3
M3 -> F2
M4 -> F1
```

四路均稳定蜂鸣，不同针位之间均不蜂鸣，轻微晃动无断续。该“反序”是两个插接面同时正视造成的几何镜像，不是导体交叉；延长线四根导体仍为一一对应。`FAN-00C` 判定为 **PASS**。

本结果不直接给四根全黑导线赋予功能，也不证明载流或长期寿命。`FAN-00D` 上电前仍须依据标准机械针位确认 `Pin 1=GND、Pin 2=+12 V、Pin 3=Tach、Pin 4=PWM`，再将针位通过本次连续性结果传递到拟改造的延长线端；不得按印刷条纹猜测。

### 18.9 FAN-00D 接法纠正：保留完整延长线（2026-10-12）

初步口头操作曾提出“剪掉延长线母座并重新剥线”，现场执行人指出两端现有压接端子、防呆外壳和应力保护均完好，剪线会引入剥线损伤、机械强度下降、重新绝缘和误标风险。该意见成立，破坏性方案在执行前撤回，现场没有剪线。

冻结后的接法改为：

```text
FAN-01 原装主母座
        <-> FANEXT-01 完整公头
FANEXT-01 完整母座 Pin 1/GND
        <-> 已复核并固定的 GND 测试引线 <-> DC 端子负极
FANEXT-01 完整母座 Pin 2/+12 V
        <-> 已复核并固定的 +12 V 测试引线 <-> DC 端子正极
FANEXT-01 Pin 3/Tach、Pin 4/PWM
        -> 本步骤不插线、不连接
```

正式接风扇前，先在延长线未接风扇的状态下给转接端短时上电，以延长线公头的 `Pin 1` 为参考测量 `Pin 2`，必须得到正的约 `12.5 V`；随后断开市电、等待指示灯熄灭并确认低于 `0.5 V`，才允许插接风扇。该方法保留成品端子和防呆结构，同时把极性错误拦截在风扇接入之前。

### 18.10 FAN-00D-A 功能针位无源绑定（2026-10-12）

适配器未上电、延长线母座四孔全部释放后，现场把风扇原装四孔主母座与 `FANEXT-01` 四针公头正常防呆插接；以风扇 PST 三针公头中已知的电源触点为参考，逐孔扫描延长线母座。执行人原始报告为：

> `FAN-00D-A：GND→F1，+12V→F2；各自唯一蜂鸣，交叉不蜂鸣；电源未上电。`

### 18.15 FAN-00F 驱动决策（2026-10-12）

ST 官方 `STM32F103x8/xB` 数据手册在针脚表中把 `PC7` 标为 `FT` 且列出复用功能 `TIM3_CH2`；`FT` 表示 5 V tolerant。电气表给出 FT 针脚输入绝对上限为 `VDD + 4.0 V`，并明确指出当外部电压高于 `VDD + 0.3 V` 时必须关闭内部上拉/下拉。以 Node A 正常 `VDD≈3.3 V` 供电计算，实测 `4.850 V` 在约 `7.3 V` 绝对上限内。

据此，H3 受控实验阶段批准 `PC7/TIM3_CH2` 使用 **Alternate Function Open-Drain，内部 Pull-Up/Pull-Down 均关闭**，直接下拉风扇 PWM；不批准推挽输出。Intel 接口上限为最大 `5 mA` 下拉电流，ST 在标准输出条件下给出 GPIO 最大 `8 mA` 吸收/输出能力，因此当前接口族的下拉电流也在 PC7 能力内。该批准附带不可省略的电源时序：Node A 必须先上电，随后才允许开启风扇 12 V；关闭时先断风扇 12 V并确认残压 `<0.5 V`，再断 Node A 或拆 PWM。因为 FT 针脚绝对上限随 `VDD` 变化，Node A 未供电时不得让风扇的 `4.850 V` 上拉进入 PC7。若最终系统不能从硬件上保证该时序，则本直连方案不得作为最终装配，必须改用外部 NPN/NMOS 隔离。

参考：ST 官方数据手册：<https://www.st.com/resource/en/datasheet/stm32f103rb.pdf>。

`FAN-00F` 判定为 **PASS（受控实验直连方案与时序约束范围）**。下一步为 `FAN-01`：风扇及 12 V 仍完全不接，在 `PC7/D9` 与 Node A `3V3` 之间加一只外部 `10 kΩ` 上拉电阻，再用示波器以 Node A GND 为参考验证约 25 kHz / 50% 的开漏低压侧波形；通过前不得进行风扇公共地和 PWM 联调。

## 24. FAN-02B 低压动态波形与测试干扰隔离（2026-10-13）

风扇 12 V/PWM/Tach、Heater 和 INA260 均保持隔离，既有 CAN 线束不动。Node A 断电后恢复 `D9/PC7→10 kΩ→3V3`，无源预检得到 `D9—3V3=9.985 kΩ`，`3V3—GND`、`D9—GND` 均不蜂鸣；重新上电后默认 `25 kHz / 50%` 稳定。

据此 `FAN-02B` 判定为 **PASS（低压动态波形范围）**：B1 单次触发、五档顺序、电平形态和结束恢复 50% 已通过。Run01/Run02 的差异作为测试工具会改变被测系统状态的实操证据完整保留。规范化记录与哈希见 [`2026-10-13 硬件证据`](../../evidence/hardware/H3/2026-10-13/README.md)。下一准入点为全断电拆除外部 10 kΩ 后的单风扇真实五档响应；Tach、Heater、INA260 继续隔离。

## 26. TACH-00A 文档/源码审计与隔离准入（2026-10-13）

既有接口基线冻结 Node A 风扇 Tach 为 `F3/Tach → PA0/A0（CN7-28）→ TIM2_CH1`，下降沿输入捕获，外部 `4.7 kΩ` 上拉到 Node A `3V3`；TIM2 在 64 MHz 时钟下配置 `PSC=639`、`ARR=65535`，计数频率为 `100 kHz`，中断优先级为 6。H0 原始物料证据中的 `R4K7-01` 静态实测约 `4.701 kΩ`，可作为本子项的指定上拉电阻。前序 `FAN-00C～FAN-00E` 已通过延长线和 PST 分支逐点映射冻结 `F1=GND、F2=+12 V、F3=Tach、F4=PWM`，因此不再靠线色或连接器外观猜测 F3 身份。

2026-10-13 源码复核确认：`.ioc` 与生成的 `tim.c` 已把 PA0 配置为 TIM2_CH1、下降沿、直连输入、无内部上下拉，且生成 TIM2 IRQ；但当前 `main.c` 只调用 `MX_TIM2_Init()`，没有 `HAL_TIM_IC_Start_IT()`，项目中也没有 `HAL_TIM_IC_CaptureCallback()` 或捕获值/RPM 计算实现。因此当前镜像只能作为 PWM 已验证镜像，**不能**把“TIM2 已配置”写成“Tach 已运行”。

首轮硬件只做 F3 电气表征，不连接 PA0/A0：保持既有 `F1/GND、F2/+12 V、F4/PWM` 回路，新增 `Node A 3V3 → R4K7-01 → F3/Tach`，示波器探头接 F3、地夹接公共 GND，PA0/A0 明确悬空。全断电先验证上拉阻值、F3 无低阻短路、3V3-GND 无低阻短路；随后严格 Node A USB 先上电、风扇 12 V 后上电。先记录风扇未供 12 V 时 F3 的静态上拉电压，再在默认 50% 转速下记录 F3 的高/低电平、频率、周期和 10 s 稳定性。只有确认波形被限制在 3.3 V 逻辑域且无异常尖峰/平台后，下一轮才允许把同一 F3 节点并接 PA0/A0。

本轮不改固件、不打开 COM7、不访问 ST-LINK，也不按 B1 跑占空比序列；其目的仅是把未知 Tach 输出类型和电平边界变成实测事实。PPR、RPM 和绝对转速继续保持 TBD，不能仅凭一个频率或行业常见值预填。

## 27. TACH-00B F3 隔离电气表征（2026-10-14）

按第 26 节的隔离方案执行，`R4K7-01` 本次实测 `4.702 kΩ`；全断电下 `F3-GND`、`F3-F2/+12 V` 和 `3V3-GND` 均不蜂鸣。F3 没有连接 A0/PA0。Node A 单独上电、风扇 12 V 仍关闭时，F3 对地为 `3.30 V` 且 10 s 稳定，证明外部上拉工作且未观察到未供电风扇把 F3 强行钳低。

据此 `TACH-00B` 判定为 **PASS（仅限 F3 隔离电气域、方波存在性与短时稳定性）**：当前 4.7 kΩ 上拉方案把 F3 限制在 3.3 V 逻辑域，未显示 5 V/12 V 误入风险。同步打开 `OBS-TACH-01`，不把边沿闪动直接写成风扇故障，也不在缺少放大波形时忽略它。下一步仍保持 A0/PA0 隔离，以 10X 探头、Peak Detect 和边沿放大确认是否存在能够二次越过输入阈值的真实毛刺；通过后才放行 PA0 输入捕获接线。`46.38 Hz` 不等于 RPM，PPR 继续保持 TBD。规范化原始报告见 [`2026-10-14 硬件证据`](../../evidence/hardware/H3/2026-10-14/README.md)。

## 28. TACH-00C 边沿视图识别出 PWM 同频尖脉冲（2026-10-14）

执行人保持 A0/PA0 断开，将探头及 CH1 均改为 10X，以 Peak Detect 观察 30 s，报告 `Vmax=3.60～3.88 V`、`Vmin=-1.92～-2.16 V`、自动频率读数从 `42.13 Hz` 短时闪至 `8.621 kHz`，Average 16 后闪动减弱；USB 无断连、无其他异常，并按逆序断电。两张原始照片完整归档。

照片复核发现，在 `25 us/div` 下屏幕重复结构的自动测量不是约 46 Hz Tach，而是约 `24.97～25.00 kHz / 40.00～40.05 us`，与已验证的风扇 PWM 完全同量级。由于全屏仅约 250 us，不可能显示多个 `21.56 ms` Tach 周期；画面实际是 Tach 高/低平台上叠加的 PWM 同频尖脉冲，示波器触发和自动频率已锁定该尖脉冲。因此本轮无法判断真正 Tach 上升/下降沿是否二次穿越 1.6 V，也不得把闪出的 kHz 数字解释为 RPM。

据此 `TACH-00C` 标记为 **HOLD（需源头隔离，不是风扇故障结论）**。报告的 `3.88 V / -2.16 V` 可能是探头地回路、F3/F4 线间耦合、公共地噪声或真实窄毛刺；在完成隔离前不放行 PA0，尤其当前 TIM2 `ICFilter=0`，即使窄毛刺不造成永久电气损伤也可能被误计为捕获边沿。下一步用相同探头设置按“F4 接通/断开、风扇 12 V 关闭/开启”的受控矩阵定位 25 kHz 成分来源，每次改变接线前均完全断电。详细逐屏读数、原始图片哈希和证据边界见 [`2026-10-14 硬件证据`](../../evidence/hardware/H3/2026-10-14/README.md)。

## 29. TACH-00D F4/PWM 源头隔离（2026-10-14）

执行人全断电后保持 F3 的 `4.7 kΩ→3V3` 上拉和 A0/PA0 隔离，完全断开 F4/PWM。
无源复核报告中，F3 测量点对 F3、F4 的结果均记为“正常”；因未另报蜂鸣状态或阻值，
本记录不把该用语扩写为额外定量结果。

只有 Node A USB 上电时，F3 平台为 `3.26 V`，观察范围 `3.16～3.36 V`，此前每约
`40 us` 重复的 25 kHz 尖脉冲消失。随后给风扇 12 V 上电、F4 仍断开，尖脉冲仍未
复现；执行人报告总体范围 `-0.12～3.48 V`。25 us/div 原始照片显示一个干净的真实
Tach 上升沿，没有 PWM 同频重复脉冲；5 ms/div 照片显示多个规则周期，屏幕读数为
`91.58 Hz / 10.92 ms / -80 mV～3.36 V`。文字报告与不同照片采集帧的瞬时极值均
原样保留，不合并成虚假的唯一常数。USB 无断连，无其他异常；完成后逆序断电并恢复

该 A/B 对照把 `OBS-TACH-01` 的 25 kHz 成分定位到 **F4/PWM 接通路径造成的耦合**：
它不是 Tach 的真实脉冲频率，且在 F4 断开、风扇 12 V 仍开启时消失，不支持把电机或

外部跳线并行段还是探测布线，因此不宣称具体物理耦合点已经确定。

F4 断开后的 `91.58 Hz` 相对默认 50% PWM 时的 `46.38 Hz` 为约 `1.974` 倍，与
控制输入撤除后的转速提高相符；但 PPR 尚未由独立证据确认，不能据此换算或宣称绝对

正常系统必须恢复 F4；而 F4 恢复后尚未加入抑制措施，TACH-00C 的 `3.88 V / -2.16 V`

## 30. TACH-00E 外部布线分离无效（2026-10-14）

F4/PWM 恢复正常接线，A0/PA0 继续隔离。执行人完成四项无源检查后，把可接触的
F3/Tach 与 F4/PWM 外露跳线尽量拉开，探测回路也远离 F4；Node A USB 和风扇 12 V
按既定顺序上电。USB 无断连，无其他异常，完成后逆序断电，A0 始终未接。

5 ms/div 的 Peak Detect 照片同时显示低频 Tach 平台和密集尖脉冲，屏幕读数为
`43.18 Hz / 23.16 ms / Vmax=3.72 V / Vmin=-2.16 V`。25 us/div 照片把尖脉冲
解析为 `24.98 kHz / 40.02 us`，该帧为 `Vmax=3.72 V / Vmin=-1.68 V`。因此本轮
最差组合极值记录为 `3.72 V / -2.16 V`，真实 Tach 记录为 `43.18 Hz / 23.16 ms`。

高平台约 3.3 V，而重复负向尖脉冲下降至 1.6 V 以下，所以每个尖脉冲都可能产生额外
下降阈值穿越；对当前 `TIM2 falling edge + ICFilter=0` 配置属于明确的假计数风险。
据此，`TACH-00E` 在受控诊断执行范围为 PASS，但“仅靠外露布线分离”作为抑制措施判定
为 **NOT EFFECTIVE**，PA0 接入继续 **HOLD**。该结果说明主要耦合不只来自可分开的
外露并行跳线，但仍不足以在完整延长线、风扇内部与其他不可分离路径之间指定唯一位置。

下一门禁不再反复调线，而是在 PA0 前搭建可拆卸 RC 测试节点，PA0 本身仍不连接：

```text
原上拉：Node A 3V3 ---- 4.7 kΩ ---- F3 raw

F3 raw ---- 10 kΩ series ----+---- filtered test point（暂不接 PA0）
                              |
                             10 nF
                              |
                             GND
```

串联输入支路名义 `10 kΩ×10 nF=100 us`、截止频率约 `1.59 kHz`；开集电极释放后的
上升过程还包含原 4.7 kΩ 上拉，名义上升时间常数约 `147 us`。这些时间尺度远短于当前
约 `43～92 Hz` 的真实 Tach 周期，同时比 25 kHz 干扰周期更适合做低通抑制；但是否
足够必须由正常 F4 接法下的 Peak Detect 实测确认，不能只凭计算放行。通过条件至少包括：
滤波点无额外 1.6 V 阈值穿越，极值回到 PA0 安全域，真实 Tach 周期仍可稳定识别，USB
无断连。详细照片和逐屏判读见
[`2026-10-14 硬件证据`](../../evidence/hardware/H3/2026-10-14/README.md)。

## 31. TACH-00F 可拆卸 RC 滤波通过（2026-10-14）

PA0/A0 继续断开，正常 F4/PWM 接法保持不变。现场在原 `3V3→4.7 kΩ→F3 raw`
上拉之后增加 `F3 raw→10 kΩ→filtered test point`，并从 filtered test point 接
`10 nF` 到公共 GND。该节点只接示波器，不接 MCU。

断电检查得到 `F3 raw→filtered=9.997 kΩ`，filtered→GND、3V3→GND、F3 raw→F4
均不蜂鸣。只有 Node A USB 上电时，filtered test point 为 `3.214 V`。正常顺序加入
风扇 12 V 后，执行人报告 Peak Detect 的另一短时窗口为 `Vmax=2.00 V / Vmin=-120 mV`，
25 kHz 残余不可见；完整 5 ms/div 照片则显示 `47.97 Hz / 20.85 ms /
Vmax=3.40 V / Vmin=-40 mV / Vavg=1.67 V` 的规则方波。短时窗口的 2.00 V 没有覆盖
完整高平台，因此不代替照片中的 3.40 V 逻辑高电平；跨采集状态最差负向极值保留
`-120 mV`。

1.6 V 判读使用波形几何而不是示波器触发电平：正常方波每周期应在上升沿和下降沿各
通过中间阈值一次；此前 25 kHz 负向尖脉冲会在高平台反复从阈值上方冲到下方，形成
额外下降穿越。本轮照片中边沿单调、平台无反弹，结合 25 kHz 残余不可见，判定为
**没有额外穿越 1.6 V**。屏幕右下角约 `557 mV` 是当时的示波器触发设置，不是 MCU
输入阈值。

本轮完整逻辑摆幅和跨采集最差负向极值均在临时准入范围 `-0.3～3.6 V` 内，真实 Tach
频率/周期互为倒数，USB 无断连且无其他异常。`TACH-00F` 判定为 **PASS（PA0 隔离条件
