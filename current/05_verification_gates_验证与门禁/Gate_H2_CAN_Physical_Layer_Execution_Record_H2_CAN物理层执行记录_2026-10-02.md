## 2. Gate 目标

1. 在全断电条件下搭建短距离双端 CAN 总线并确认两端终端并联约 `60 Ω`；
2. 核对两块 NUCLEO 与对应 CAN Pal 的 `3.3 V/GND/PA11-RX/PA12-TX/SLNT` 连接；
3. 先以固定帧和递增计数器验证双向收发，再接入正式 `0x100/0x180`；
4. 记录 ID、DLC、payload、Tx/Rx counter、CAN error state 与断开一端时的可观察行为；完整应用 timeout/fault 状态机明确递延到后续 Gate。

本 Gate 不验证 12 V 功率链、Fan/Heater/INA260/NTC、完整 Fault 逻辑或完整 FreeRTOS 应用闭环。

## 4. Gate 关闭结论

Gate H2 于 **2026-10-07 PASS**。结论由以下相互独立的证据共同支撑：

1. 全断电终端电阻从两端复测为 `60.3 Ω/60.4 Ω`；
2. 固定诊断帧连续 `3×80 s` 双向收发通过；
3. 正式 `0x100/DLC2` 与 `0x180/DLC5` 在 `80 s` 窗口内通过 ID、DLC、payload 和 AliveCounter 校验；
4. 断开 H/L 后双方错误状态与收发中断明确可见；
5. 恢复过程中两次高错误状态没有被误判为通过，重新检查连接后先通过 `30 s` 预检，再通过最终 `80 s` 稳定窗口；
6. 失败日志、通过日志、ELF 哈希和逐文件 SHA-256 均已归档。

H2 PASS 只授权进入下一低风险 Gate 的准备工作。全部 `12 V`、Fan、Heater、INA260、NTC 和其他功率外设继续保持禁止接入，直到相应 Gate 单独放行。完整应用 timeout、故障确认/恢复逻辑、负载、耐久和 EMC 不属于本 Gate 结论。
